# Dogs

Aplicação frontend desenvolvida com React que simula uma rede social simples para pets, inspirada em um feed de compartilhamento de fotos.

## Visão geral
Este projeto foi criado com foco no aprendizado de conceitos reais de frontend, como fluxo de autenticação, consumo de APIs, composição de componentes e gerenciamento de estado da interface.

## Funcionalidades
- Autenticação de usuários
- Upload e exibição de imagens
- Feed com scroll infinito
- Perfis de usuário
- Interações básicas (curtidas e comentários)

## Tecnologias utilizadas
- JavaScript
- React
- Vite
- CSS
